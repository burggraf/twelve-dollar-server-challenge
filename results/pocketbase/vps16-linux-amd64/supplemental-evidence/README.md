## Historical-script safety and reproduction limits

**Do not execute historical controllers as an installer or resume command.** Several preserved scripts have top-level lifecycle effects and hard-coded native owned paths. Source availability grants no execution authority; all stopped phases are immutable. Product tests, builds and load belong on the designated native VPS only, never the Mac. No new PocketBase load is authorized by closure.

The actual frozen native common code predates newer local Convex/common changes. Never sync this current checkout over the frozen PocketBase tree and call it the measured source. Complete source/module/private archives remain retained with hashes, pending privacy/license/distribution review. No public external raw locator, standalone fresh-checkout reproduction, new build or new CI execution is claimed.

To verify complete original bundle checksum files, obtain **all original** raw/source files and any unredacted original manifests/logs whose public derivative differs. Merely restoring raw gzip files beside a redacted manifest is insufficient. Never regenerate historical checksums to make a derivative pass an original identity. To check public supplement bytes only, run `sha256sum -c SUPPLEMENTAL_SHA256SUMS` from the parent directory, or use a local SHA256 implementation for bookkeeping. Native source/secret/test evidence is separate from such a local checksum check.
