## Caching and native configuration

The pinned [self-hosted tuning guide](https://github.com/get-convex/convex-backend/blob/a3538c6d212948f20726868e41d155d2534cd130/self-hosted/advanced/knobs.md) documents environment-configured native knobs. This profile sets **`UDF_CACHE_MAX_SIZE=0`**. The pinned backend initializes its `QueryCache` from that knob; both ready-result and waiting-result entries are evicted until the configured size is satisfied. Three real native tests passed after missing-function reds: storage reads, rejection of unauthenticated internal-function calls, and repeated identical queries executing without cache hits/shared-result waits while retained cache bytes remained zero ([red](../../results/convex/implementation-checks/native-storage-query-red.log), [green](../../results/convex/implementation-checks/native-storage-query-green.log)). Optional outbound beacon is disabled. No app response, count, or JWT-verification cache is allowed.
